# Segurança e divulgação responsável

Este repositório é destinado à apresentação pública do projeto. Não publique vulnerabilidades exploráveis, credenciais, tokens, chaves privadas, dados pessoais ou detalhes de infraestrutura privada.

## Relato privado

Se encontrar um possível problema de segurança, não publique detalhes exploráveis em uma issue pública. Entre em contato diretamente com o mantenedor por um canal privado que ele tenha divulgado.

## Antes de publicar alterações

- Revise os arquivos e o histórico do Git em busca de segredos.
- Remova `.env`, dumps de banco, logs, sessões e dados reais.
- Use apenas capturas de tela revisadas e sem informações pessoais.
- Confira se os documentos não expõem rotas, configurações ou detalhes internos desnecessários.

Este documento não constitui uma promessa de auditoria ou certificação de segurança.
