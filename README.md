# TarScalls — Showcase

**TarScalls** é um projeto de plataforma social em desenvolvimento, com foco em comunidades, conversas e personalização de perfil. Este repositório público apresenta a visão, as funcionalidades e a direção do produto, sem publicar o código-fonte privado nem configurações internas.

> **Status:** em desenvolvimento. As funcionalidades descritas podem estar em diferentes estágios de implementação e validação.

## Objetivos

- Reunir comunidades em espaços organizados.
- Facilitar conversas e conexões entre usuários.
- Oferecer uma interface própria, com identidade visual distinta.
- Evoluir com atenção à segurança, acessibilidade e uso responsável de recursos.

## Funcionalidades em desenvolvimento

- **Comunidades e servidores:** espaços para organizar pessoas e conversas.
- **Canais:** organização de conversas por assunto.
- **Perfis:** informações e personalização da apresentação do usuário.
- **Amizades:** envio e remoção de conexões entre usuários.
- **Gestão de servidor:** opções de edição para quem administra um servidor.
- **Presença e interação:** recursos sociais planejados para tornar as comunidades mais dinâmicas.

Consulte [`docs/FEATURES.md`](docs/FEATURES.md) para ver o escopo resumido e [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) para uma visão de alto nível, sem detalhes sensíveis.

## Privacidade e segurança

Este repositório é um **showcase**, não uma distribuição do aplicativo. Não inclua `.env`, credenciais, tokens, chaves, dados de usuários, bancos de dados, logs privados, arquivos de configuração de produção ou código-fonte que você queira manter privado. Veja [`SECURITY.md`](SECURITY.md).

## Tecnologias

O projeto principal utiliza tecnologias web. A stack e os detalhes de implementação podem evoluir; este repositório evita expor configurações internas e não deve ser usado como instrução de instalação do aplicativo.

## Estado do projeto

O projeto está em desenvolvimento ativo. Recursos, telas e decisões técnicas podem mudar conforme a implementação e os testes avançam. Este repositório documenta a proposta pública do TarScalls.
