# Contribuindo com o showcase

Este repositório serve para documentar publicamente a proposta do TarScalls. Antes de abrir uma issue ou pull request:

1. Descreva a melhoria de forma objetiva.
2. Não inclua código privado, credenciais ou dados pessoais.
3. Para imagens, confirme que tem autorização para publicá-las e que não revelam informações de usuários.
4. Evite afirmar que funcionalidades estão concluídas sem validação.

A publicação de código-fonte do aplicativo principal não faz parte do objetivo deste repositório.
